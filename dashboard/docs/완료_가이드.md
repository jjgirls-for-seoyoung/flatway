보행 및 휠체어 사용자를 위한 실시간 단차 및 노면 안전 지도 대시보드 **FlatWay**의 1차 구현이 완료되었습니다!

## 🛠️ 작업 내용 요약

### 1. 프로젝트 기본 환경 세팅
* **Next.js (App Router):** 최신 React canary 버전을 내장한 Next.js 프로젝트를 초기화하였습니다.
* **디자인 시스템 및 CSS:** [globals.css](file:///c:/Users/User/Desktop/flatway/dashboard/src/app/globals.css) 파일에 모던 다크 테마 및 Glassmorphism 효과, 그리고 위험도를 알리는 고대비 안내 디자인 토큰을 정의하여 아름다운 웹 UI를 구현하였습니다.
* **의존성 설치:** `@supabase/supabase-js`, `leaflet`, `react-leaflet`, `lucide-react`를 설치하여 컴포넌트 구성을 마쳤습니다.

### 2. 컴포넌트 설계 및 구현
* **[page.js](file:///c:/Users/User/Desktop/flatway/dashboard/src/app/page.js):** 메인 대시보드 페이지. 실시간 안전 지표, 통계 카드, 필터링 체크박스, 이동 수단 모드 선택기 및 상세 패널을 관리합니다.
* **[SafetyMap.js](file:///c:/Users/User/Desktop/flatway/dashboard/src/components/SafetyMap.js) & [DynamicMap.js](file:///c:/Users/User/Desktop/flatway/dashboard/src/components/DynamicMap.js):** Leaflet 기반 지도를 클라이언트 사이드에서 안전하게 로드합니다. 커스텀 마커 렌더링, 수동/전동 휠체어 전용 경로 라인 그리기, 지도 클릭 좌표 캡처를 담당합니다.
* **[ReportModal.js](file:///c:/Users/User/Desktop/flatway/dashboard/src/components/ReportModal.js):** 탭한 좌표로 실시간 단차/노면 위험 요소를 제보할 수 있는 모달 시뮬레이터 폼입니다.
* **[supabaseClient.js](file:///c:/Users/User/Desktop/flatway/dashboard/src/lib/supabaseClient.js) & [.env.local](file:///c:/Users/User/Desktop/flatway/dashboard/.env.local):** Supabase 연결 도구로, 로컬 테스트 편의를 위해 자격 증명이 활성화되지 않았을 때는 **자동으로 브라우저 로컬 저장소(localStorage) 데이터 모드로 실행**되는 지능형 폴백을 구축했습니다.
* **[mockData.js](file:///c:/Users/User/Desktop/flatway/dashboard/src/data/mockData.js):** 작전역 및 작전여고 인근의 4.5cm 단차 턱 정보, 노면 파손 정보, 건물 경사로 설치 데이터 및 경로 좌표를 선탑재했습니다.

### 3. 데이터베이스 연동 문서
* **[supabase_schema.sql](file:///c:/Users/User/Desktop/flatway/dashboard/docs/supabase_schema.sql):** Supabase 대시보드의 SQL Editor에 직접 복사-붙여넣기하여 실행할 수 있는 데이터베이스 테이블 스키마 구축 및 샘플 시드 파일입니다.

## 🚀 로컬에서 실행 및 테스트하는 방법

### 1. 개발 서버 실행
터미널에서 아래 명령을 실행하여 Next.js 개발 서버를 구동합니다:
```bash
npm run dev
```
이후 브라우저에서 `http://localhost:3000`에 접속합니다.

### 2. 핵심 기능 시나리오 테스트
1. **이동 수단 모드 선택:**
   - 왼쪽 패널의 **[보행자]**, **[전동휠체어]**, **[수동휠체어]** 버튼을 클릭해 봅니다.
   - 각 모드에 맞춰 지도에 파손 노면과 단차를 우회하는 서로 다른 색상의 경로선(Polyline)이 업데이트되는 것을 확인합니다.
2. **지도 필터링:**
   - **단차**, **파손/급경사**, **건물** 스위치를 조글하여 지도 위의 핀들을 동적으로 켜고 끕니다.
3. **제보 등록 시뮬레이션 (핵심):**
   - 지도 위의 비어있는 도로를 **클릭(탭)**하면 좌표 정보와 함께 `🚨 실시간 노면 안전 제보하기` 모달이 팝업됩니다.
   - 유형, 높이(단차일 때), 심각도, 상세 내용을 적고 **[제보 등록하기]**를 누릅니다.
   - 등록 완료 알림과 함께 **종합 안전 점수가 동적으로 삭감**되며, **미해결 노면 위험 통계치 증가** 및 **새로운 위험 마커 핀**이 지도 위에 실시간으로 나타납니다.
4. **상세 조회:**
   - 지도 위의 특정 핀(경사로 건물 또는 위험 핀)을 클릭하면 팝업 정보창이 뜰 뿐만 아니라, 왼쪽 하단의 **[세부 정보 조회]** 패널에 각 항목의 상세 속성이 로드됩니다.

## 🗄️ Supabase 연동 방법
1. Supabase 프로젝트 콘솔로 이동하여 **SQL Editor**를 열고 [supabase_schema.sql](file:///c:/Users/User/Desktop/flatway/dashboard/docs/supabase_schema.sql) 파일 내용을 실행합니다.
2. 프로젝트의 API Credentials에서 **URL**과 **Anon Key**를 복사합니다.
3. 프로젝트 폴더의 [.env.local](file:///c:/Users/User/Desktop/flatway/dashboard/.env.local) 파일의 플레이스홀더를 변경하고 저장합니다.
4. 개발 서버를 재실행하면 로컬 저장소 모드가 해제되고 Supabase DB와 완벽하게 양방향(Read/Write) 연동됩니다.
