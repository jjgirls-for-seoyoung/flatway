# FlatWay 보행 안전 지도 및 모바일 앱 개발 계획

휠체어 및 이동 약자를 위한 보행로 단차와 노면 파손 실시간 안내 서비스인 **플랫웨이(FlatWay)**의 전체 개발 계획입니다.

```
[Flutter 모바일 앱] (측정 및 위치 제보)
       │
       ▼
 [Supabase 데이터베이스] (데이터 저장 및 RLS 보안)
       │
       ▼
 [Next.js 대시보드] (지도 시각화 및 관리자 모니터링)
```

---

## 1. 개요 및 요구사항
* **서비스 목적:** 이동 약자(휠체어, 유아차 사용자 등)에게 보행 장애물(단차, 노면 파손 등) 정보와 건물 접근성(경사로, 엘리베이터 등) 정보를 실시간으로 공유하고 안전한 이동 경로를 안내함.
* **시스템 구조:**
  - **Flutter 모바일 앱 (`flatway_app`):** 사용자 위치 기반 단차/노면 파손 제보 및 최적 이동 경로 안내.
  - **Supabase (PostgreSQL):** 실시간 데이터 수집 및 관리를 위한 백엔드 DB (`hazards`, `buildings` 테이블).
  - **Next.js 대시보드 (`dashboard`):** 수집된 안전 지표 시각화 및 관리자 모니터링 뷰.

---

## 2. 보안 및 환경 설정 (Supabase RLS 적용)

> [!IMPORTANT]
> **Supabase RLS(행 수준 보안) 활성화**
> 현재 `hazards` 및 `buildings` 테이블의 RLS가 비활성화되어 있어 무단 데이터 수정 위험이 존재합니다.
> 보안 강화를 위해 다음 SQL 정책을 적용합니다.

```sql
-- 1. RLS 활성화
ALTER TABLE public.hazards ENABLE ROW LEVEL SECURITY;
ALTER TABLE public.buildings ENABLE ROW LEVEL SECURITY;

-- 2. hazards 조회 및 제보 등록 정책 (public / anon / authenticated)
CREATE POLICY "Allow public select on hazards" ON public.hazards FOR SELECT TO public USING (true);
CREATE POLICY "Allow public insert on hazards" ON public.hazards FOR INSERT TO public WITH CHECK (true);

-- 3. buildings 조회 정책 (public / anon / authenticated)
CREATE POLICY "Allow public select on buildings" ON public.buildings FOR SELECT TO public USING (true);
```

## 3. 단계별 개발 로드맵

### 1단계: Supabase 데이터베이스 보안 및 API 정책 적용
- RLS 정책 실행 및 public access 유효성 테스트.
- Supabase Data API 및 익명 API 키 연동 점검.

### 2단계: 모바일 앱(`flatway_app`) 패키지 구성 및 Supabase 초기화
- `pubspec.yaml` 의존성 추가 (`supabase_flutter`, `flutter_map`, `latlong2`, `geolocator`).
- `lib/main.dart` 내 Supabase 클라이언트 초기화 및 접속 유틸리티 세팅.

### 3단계: 모바일 앱 핵심 UI & 기능 구현
- **화면 ①: 지도 및 우회 경로 안내** (`flutter_map` 활용)
  - 사용자 위치 수집 및 주변 단차/파손 마커 표시.
  - 이동 수단(보행자 / 전동 휠체어 / 수동 휠체어) 모드별 가상 우회 경로 표기.
- **화면 ②: 단차/파손 실시간 제보 모달**
  - 단차 높이(cm), 심각도(상/중/하), 사진 및 설명 작성 후 Supabase `hazards` 테이블에 `INSERT`.
- **화면 ③: 건물 접근성 바텀시트**
  - 건물 클릭 시 경사로, 승강기, 자동문 유무 및 사진 정보 표시.

### 4단계: Next.js 웹 대시보드 실시간 연동 강화
- `dashboard/src/app/page.js` Supabase 연동 로직 고도화.
- 앱에서 새로 등록된 제보가 웹 지도 대시보드에 즉시 실시간 렌더링되도록 처리.

### 5단계: 통합 테스트 및 검증
- Flutter 앱 실시간 제보 -> Supabase 저장 -> Next.js 대시보드 즉시 반영 전 과정 E2E 테스트.
