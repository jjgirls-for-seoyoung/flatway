# 📱 FlatWay 모바일 앱 (Flutter)

본 프로젝트는 이동 약자(휠체어 및 유아차 사용자 등)를 위한 실시간 보행로 단차/파손 정보 측정 및 안전 경로 안내 모바일 애플리케이션입니다.

---

## 🚀 개발 상황 및 진행 방향
> [!IMPORTANT]
> **초기 템플릿 기반 점진적 확장 개발**
> - 현재 프로젝트는 Flutter 초기 기본 구성인 **카운터(Counter) 앱 템플릿**으로 세팅되어 있습니다.
> - 앞으로의 모바일 앱 개발은 이 기본 카운터 앱을 기반으로 코드를 수정 및 확장하여, 실제 구현하고자 하는 FlatWay 핵심 기능들을 얹는 방식으로 진행할 예정입니다.

---

## 🛠️ 모바일 앱 핵심 개발 계획 (Next Steps)

1. **디폴트 카운터 앱 분석 및 점검:**
   - 생성된 초기 프로젝트의 빌드 상태 및 디바이스(에뮬레이터) 정상 작동 확인.
2. **UI 레이아웃 개편 (`lib/main.dart` 수정):**
   - 기존 카운터 UI를 제거하고, 지도(Map API) 연동 영역 및 검색/제보 조작 컴포넌트를 설계합니다.
3. **Supabase 데이터베이스 연동:**
   - 대시보드 웹과 공동으로 공유하는 Supabase 프로젝트(`wevesokdfrrtfmjbcprq`)에 접속할 수 있도록 `supabase_flutter` 패키지를 설치하고 초기화 설정을 진행합니다.
4. **보행 장애 요소 측정 및 실시간 제보 기능 구현:**
   - 단차 높이, 노면 파손도 등을 사용자가 현장에서 제보하거나 센서(GPS, 가속도계 등)를 활용해 수집하고, 이를 Supabase `hazards` 및 `buildings` 테이블에 실시간으로 `INSERT`하는 기능을 완성합니다.

## 📂 폴더 구조 및 실행 방법

### 1. 폴더 구조
*   `lib/main.dart`: 메인 엔트리포인트 및 앱 UI 구현부 (현재 카운터 템플릿 코드가 적용되어 있습니다.)
*   `pubspec.yaml`: 패키지 의존성 정의 파일 (추후 Supabase 및 지도 SDK 추가 예정)

### 2. 로컬 실행 방법
모바일 폴더로 이동한 뒤 Flutter 명령어를 통해 빌드 및 실행을 진행합니다.
```bash
cd flatway_app
flutter pub get
flutter run
```
