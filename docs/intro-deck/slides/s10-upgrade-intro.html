고도화 첫 페이지 (약 40초). 성형외과의 비포 애프터처럼 한 줄씩 보여 준다. 사용자가 앱에 들어가서 만나는 순서대로다. 접속은 설치에서 링크와 QR로, 첫 사용은 설명 없음에서 말풍선과 10단계 가이드로, 위험 종류는 제각각에서 네 가지로 통일, 길찾기는 최단 경로만에서 위험을 피하는 이동 수단별 길로, 길안내는 경로선만 보이던 것에서 내 위치를 따라가는 음성 안내로 바뀌었다. 다음 장부터 다섯 가지를 하나씩 자세히 본다.
