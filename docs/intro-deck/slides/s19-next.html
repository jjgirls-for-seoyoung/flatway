앞으로의 계획 (약 30초). 왼쪽은 곧 적용할 것이다. 이메일 로그인과 내 제보는 코드를 만들어 두었고 메일 발송 설정만 하면 공개한다. 제보는 누구나 쓰되 삭제와 수정은 관리자만 하도록 서버 권한 설정도 적용할 예정이다. 오른쪽은 아직 구현하지 못한 것을 솔직하게 소개한다. 고도 데이터를 연동한 실제 경사도 반영, 건물 내부 연계, 센서 교차검증 점수, 허용 단차와 경사를 직접 입력하는 개인 기준이 모두 개발 계획 중이다. 교차검증은 같은 위치를 지나간 다른 사용자의 센서 기록과 비교해 신뢰도 점수를 매기는 방식이다. 50퍼센트 미만은 검증 대기, 50퍼센트 이상은 정식 위험 핀으로 등록해 허위 제보를 막는다. 지금은 제보 상세의 ‘도움이 돼요’ 확인 버튼까지 제공한다.
