고도화 한눈에 보기 (약 30초). 8월 19일부터 작업 기록이 180회, 함께 만든 팀원은 4명, 자동 테스트는 21개다. 고도화에서 눈에 띄는 개선 다섯 가지를 날짜순으로 보면 10월 18일 웹 접속과 위험 4종 카테고리, 10월 23일 첫 사용 가이드와 이동 수단별 위험 회피 길찾기, 11월 3일 실시간 길안내다. (날짜와 작업 횟수는 작업 기록 기준)
