교차 검증 계획 (약 40초). 아직 만들지 않은 계획이다. 1) 제보가 들어오면 먼저 검증 대기로 저장한다. 2) 근거를 모아 점수를 매긴다. 제보 위치 반경 20미터 안을 지난 다른 사용자의 센서 충격 기록이 가장 강한 근거이고, 서로 다른 계정의 같은 제보, 사진, 이메일 로그인 계정이 보조 근거다. 본인의 센서 기록과 같은 계정의 중복 제보는 빼서 스스로 검증하는 것을 막는다. 3) 50점이 넘으면 정식 핀으로 지도와 경로 계산에 반영하고, 넘지 못하면 반투명한 검증 대기 핀으로 경로 계산에서 뺀다. 관리자가 직접 확인하면 점수와 상관없이 바로 확정하거나 제외한다. 포인트도 정식으로 확정된 제보에만 주는 것이 목표다. 배점은 현장 테스트로 조정한다. (자세한 점수 기준은 README의 교차 검증 상세 계획)
