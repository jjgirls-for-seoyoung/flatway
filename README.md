# ♿ FlatWay (플랫웨이) - 보행 약자 맞춤형 도로 단차 안내 및 대시보드 시스템

> **휠체어 및 이동 약자를 위해 길 위의 단차와 노면 파손 정보를 센서로 자동 수집하고, 맞춤형 안전 우회 경로를 실시간으로 제공하는 스마트 내비게이션 솔루션입니다.**

---

## 🗺️ 프로젝트 개요 (Overview)

기존의 상용 네비게이션 서비스는 차량 또는 일반 보행자 위주로 설계되어 있어, **2cm 이상의 미세한 보도 턱(단차), 보도블록 파손, 급경사 구간** 등 휠체어 사용자에게 치명적인 보행 장애물 정보를 제공하지 못합니다. 

**FlatWay**는 모바일 앱(Flutter)의 고주파 센서 수집 기술과 웹 대시보드(Next.js)의 시각화 및 경로 우회 알고리즘을 Supabase 실시간 DB로 연결하여, 이동 약자가 목적지까지 끊김 없이 안전하게 이동할 수 있는 **'도어 투 도어(Door-to-Door)'** 무장애 길 안내 환경을 구축합니다.

---

## 🚀 주요 기능 (Key Features)

### 📱 1. FlatWay 모바일 앱 (Flutter)
* **센서 기반 자동 노면 스캔:** 스마트폰 내장 가속도계 센서를 활용해 100Hz 주파수로 주행 진동을 감지하고, 단차 발생 구간의 충격 피크(Peak)를 검출하여 위경도 좌표와 함께 서버로 자동 업로드합니다.
* **실시간 도로 장애 제보:** 보도 턱, 노면 파손, 불법 적치물 등 위험 요소를 발견했을 때 터치 몇 번으로 손쉽게 현장 정보를 입력해 제보할 수 있습니다.
* **이동 수단 모드별 맞춤 경로:** 일반 보행, 전동 휠체어, 수동 휠체어 등 사용 기기 특징에 최적화된 경로선 및 음성 안내를 매핑하여 제공합니다.

### 💻 2. FlatWay 대시보드 웹 (Next.js)
* **실시간 위험 요소 시각화:** Supabase DB와 연동하여 수집된 도로 단차 및 건물 편의 시설 데이터를 지도 상에 다양한 마커(핀)로 실시간 렌더링합니다.
* **개인별 맞춤 이동 한계 설정 (Custom Thresholds):** 사용자가 직접 허용 가능한 단차(cm)와 최대 경사도(°)를 설정하면, 경로 상의 위험 정보를 탐색하여 기준 초과 시 안전한 우회 경로로 자동 재탐색을 실행합니다.
* **도어 투 도어 실내외 통합 안내:** 건물 입구의 경사로 유무뿐만 아니라, 건물 내부의 승강기(엘리베이터) 위치까지 이어지는 실내 경로(점선)를 한 화면에서 확인할 수 있습니다.

### 🛡️ 3. 데이터 신뢰성 & 어뷰징 검증 (Trust & Verification)
* **센서-제보 교차 검증:** 특정 사용자가 수동 제보한 위치의 반경 20m 이내를 지나간 다른 사용자의 자동 센서 충격 데이터를 매칭하여 허위 제보를 판별합니다.
* **신뢰 점수(Trust Score) 제어:** 신뢰 점수가 50% 미만인 제보는 지도 상에 반투명한 노란색 핀(검증 대기)으로 표기되며 경로 안내 연산에서 제외되고, 기준 충족 시 정식 핀으로 활성화됩니다.

```
┌────────────────────────┐         ┌────────────────────────┐
│     FlatWay Mobile     │         │   FlatWay Dashboard    │

└───────────┬────────────┘         └───────────┬────────────┘
            │                                  │
            │  (Realtime Read/Write)           │  (Realtime Read/Write)
            ▼                                  ▼
      ┌──────────────────────────────────────────────┐
      │             Supabase Database                │
      │   - hazards table (단차/파손/경사 정보)      │
      │   - buildings table (건물 편의시설 정보)    │
      └──────────────────────────────────────────────┘
```

## 🛠️ 시작 가이드 (Getting Started)

### 1. 전제 조건 (Prerequisites)
* [Node.js](https://nodejs.org/) (v18 이상 권장)
* [Flutter SDK](https://docs.flutter.dev/get-started/install) (v3.13 이상 권장)

### 2. 웹 대시보드 실행 방법
```bash
# dashboard 폴더로 이동
cd dashboard

# 의존성 패키지 설치
npm install

# 로컬 개발 서버 실행
npm run dev
# -> http://localhost:3000 에서 접속 및 테스트 가능
```

### 3. 모바일 수집 앱 실행 방법
```bash
# flatway_app 폴더로 이동
cd flatway_app

# 의존성 패키지 설치
flutter pub get

# 시뮬레이터 또는 실기기에서 실행
flutter run
```
